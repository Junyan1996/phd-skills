# 论文与开题预审

确定材料范围、审阅目标和标准。全文、摘要、图例或方案节选分别界定可评估范围；缺少方法不等于方法一定有缺陷。按实际学科/学位/期刊要求评估，不默认Nature门槛或固定三名审稿人。

先提取共同事实：核心问题、贡献主张、可见证据、设计、比较、验证和限制。审阅主轴：

- 问题与贡献：是否有清楚缺口和最近工作对照；新颖性是否经过适当查新。
- 设计与证据：独立单位、样本选择、混杂、控制、统计、效应与不确定性、技术与生物学替代解释。
- 推断：资源/关联/预测/机制主张是否与证据相称；独立验证是否真独立。
- 可复现与表达：方法、数据/代码、图表、引用与限制是否可检查。
- 开题另查数据与资源是否具备、任务依赖、学位期限、失败备选和可验收成果。

每条问题给“定位—可见事实—影响—建议—核验方式”。区分必须解决的实质问题、改善建议和材料不足无法判断；优先修复影响核心主张的问题，不要求无关的大量新实验。已有正确边界的描述性研究不因缺少机制而自动判失败。

若用户要求多视角审稿，各视角共享同一事实底稿，仅侧重不同；不虚构真实审稿人身份、机构或编辑决定。需要最新文献/政策时检索原始来源；只看局部材料时不能断言整篇无新意。

交付总体评价、优势、按优先级的问题和修订路径。不要未经请求直接改稿；回复审稿人的任务另按作者响应处理。结论是模拟预审，不能保证录用或学校批准。
