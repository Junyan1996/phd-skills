# 选题与科研决策

先从用户已有想法/困境、目标期限、材料和资源出发，不重新做固定问卷。识别当前任务是新题筛选、已有题收缩，还是技术故障影响立题。

1. 用一句话写问题、现有限制和可能贡献；区分生物学发现、方法改进与资源建设。贡献大小不等于技术复杂度或期刊名。
2. 把文献支持、用户观察、推测与未验证前提分开。做与该决定相称的最新查新，记录查询与边界；没有检索条件时把新颖性列为待核。
3. 比较少量真正不同的方案：科学价值/使用价值、最近工作差异、样本与技术可得性、技能与算力、关键依赖、期限内的最低可交付成果。不虚构成功概率和精确综合分数；用户需要权重时说明主观依据与敏感性。
4. 找出最可能改变方向的前提，设计最早、低成本且可判别的可行性试验。写清“什么观察→继续/缩小/转向”，并指出阴性或不确定结果的含义。
5. 项目卡住时先区别技术失败、设计不可识别和核心假设受反证；不要以换软件掩盖混杂或样本不足。优先保留有证据支持且与毕业目标相关的部分。

交付一份紧凑决策简报：推荐方向及理由、备选、最接近工作、未验证前提、首个检验、继续/转向条件、下一行动。推荐是可修订判断，不是保证发表或毕业。若只需局部决策，不扩展为完整开题。
