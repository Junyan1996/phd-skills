# 论文分节任务

| 部分 | 写作任务 | 易漏边界 |
|---|---|---|
| Title | 指出研究对象和被支持的主要贡献 | 不超出研究系统、设计和证据 |
| Abstract | 问题、缺口、方法范围、主要证据、贡献与边界 | 不加入正文没有的结果，数字必须可追溯 |
| Introduction | 从具体重要问题收敛到未解决问题及本文切入 | 不以大领域口号代替具体缺口，不提前夸大结论 |
| Results | 按科学问题推进证据，说明比较、效应与不确定性 | 区分观察与解释；每节有可定位图表支持 |
| Methods | 让关键设计与分析可复现 | 样本来源/单位、QC、排除、模型、版本、参数与验证 |
| Discussion | 回答问题、对照已有工作、解释替代、限制和意义 | 不重述全部结果，不把假说当验证后的机制 |
| Conclusion | 凝练已建立贡献与适用范围 | 不承诺尚未测试的应用效果 |

Methods论文增加强基线、公平评估和失败案例；资源论文增加质量多维验证、访问和用途；综述明确检索/选择边界。目标期刊要求应查其当前官方作者指南，不将任何一家子刊规则推广至整个刊系。
