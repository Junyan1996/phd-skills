# 按当前交付选择科研能力

只在阶段确实需要时读取本表，再打开所选且实际安装的技能；名称不证明工具已存在。

| 当前任务 | 可选技能 |
|---|---|
| 选题/取舍 | `phd-topic` |
| 开题/研究计划 | `phd-proposal` |
| 文献检索与综合 | `phd-literature` |
| 问题、假说与研究设计 | `phd-hypothesis` |
| 生信设计/代码/排错 | `phd-bioinformatics` |
| 论文精读与对照 | `phd-reader` |
| 论文起草/语言润色 | `phd-writing` / `phd-polishing` |
| 引文支持与参考文献 | `phd-citation` |
| 数据/代码可用性 | `phd-data` |
| 科研图/学术汇报 | `phd-figure` / `phd-slides` |
| 稿件或开题预审 | `phd-reviewer` |
| 审稿回复与返修 | `phd-response` |
| 已确认PMID的检索式留出验证 | `phd-pubmed` |

可复用现有技能及工具替代上述名称。一个明确的小任务直接交给相应能力，不先强制走完整选题—检索—开题流程；本技能单独安装仍可维护计划和续接状态。
