# LaTeX布局检查

1. 保留原稿；识别文档类、编译器、字体与缺失资源。优先使用当前环境已有的受支持编译器，不假定终端TeX已安装。
2. 记录有问题的页：孤立标题、大片空白、浮动体队列、过大图、长表、越界、字体替换。对照日志中的overfull/underfull与实际页面；警告不是每次都可见，页面好看也不代表资源齐全。
3. 判断根因：图片自身留白/比例、固定高度、过多强制分页、过严浮动限制、不可分盒子、标题后空间。优先修图像边界、合理尺寸与浮动策略；不要批量使用负间距、`[H]`或`\clearpage`掩盖问题。
4. 多面板图若内容本来过扁，回到图源调整行列和面板比例，保持文字可读；不能拉伸图改变几何意义。
5. 改动后用相同设置编译，检查受影响页及前后页，确认编号、引用、目录和浮动体顺序。对缺失编译能力明确写“源已修改，版式尚未验证”。
