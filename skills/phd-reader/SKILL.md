# 论文精读与对照读本

先确定用户要摘要、精读、全文对照还是局部翻译；全文请求不能悄悄降为摘要。确定文章身份与版本、来源文件和实际可读取范围。

用户提供的可处理全文按请求翻译；只有链接/DOI时先获取合法可用来源，并遵守适用版权边界，不能因可访问就输出受限全文或完整翻译。限制影响全文交付时明确说明，提供可允许的有定位讲解或请求用户提供正文。

1. 建立原文映射：章节、段落、页码、图表、补充材料及缺页。PDF页码与印刷页码可分别记录；HTML保留章节/段落锚点。
2. 对照翻译保持术语、符号、数值、限定和引用一致；公式/表格/扫描文字回看原件，OCR不确定处标记，不能补造看不清的内容。
3. 图表放在解释它的段落附近，保留图号、面板、图例和来源；裁图保留比例尺、色标、必要坐标，嵌图用真实可访问文件路径。无法提取时明确占位及影响，不声称已看见。
4. 每个讲解区分“作者报告”“我的解释”“证据限制/替代解释”；机制图、富集、相关与因果证据分开。按问题→设计→关键证据→结论边界梳理论证。
5. 建立术语表，区分基因与蛋白、模型与数据集、指标与缩写；后续问答引用相同原文定位，不从先前摘要重新猜细节。

大读本交付 `paper.md`、来源映射和覆盖说明，必要时附图表文件；全文不完整时列已处理/未处理章节与原因。短请求按比例输出，不强制产生多文件。可定位性和准确性优先于流畅补写。
