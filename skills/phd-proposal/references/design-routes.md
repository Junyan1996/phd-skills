# 按研究类型分流

可组合路线，只读与本项目相关部分。

| 路线 | 应明确的设计 | 常见越界 |
|---|---|---|
| 群体/进化遗传 | 采样分层、亲缘、群体结构、人口史与选择的替代解释、独立验证 | 把结构/人口史信号直接写成适应机制 |
| 数量遗传/GWAS/育种 | 表型重复和环境、亲缘/结构、有效样本量、多重检验、独立验证或预测外推 | 把关联位点等同致因基因，随机拆分近亲导致泄漏 |
| 功能遗传/机制 | 扰动与对照、独立重复、时间顺序、脱靶/补救、备选机制 | 单个表达变化或过表达表型证明完整机制 |
| bulk/单细胞/空间组学 | 独立个体、批次与组别可分离性、处理层级、注释不确定性、跨层验证 | 把细胞/切片/测序reads当作独立个体；批次完全混杂后靠算法补救 |
| 多组学整合 | 样本匹配、层间方向、缺失模式、整合相对单组学基线的增益 | 相关网络证明调控方向，多个衍生层面当作独立验证 |
| 基因组/泛基因组资源 | 数据适配、表示与版本、质量维度、困难区域、使用场景与基线 | N50更大即生物学创新，一个个体证明群体规律 |
| 方法/预测模型 | 目标任务、强基线、公平预算、按个体/家系/地点拆分、嵌套调参、外部测试 | 用测试集筛特征/选参数，同源数据重复计入训练和测试 |
| 微生物遗传/宏基因组 | 分离株/宿主/环境单位、污染、组成性、参考库与检出偏差 | 相对丰度变化等同绝对数量变化，批次/宿主混杂被忽略 |

关联、预测、资源质量和机制是不同产物。每种主张都要明确可识别的分析单位、支持它的比较，以及无法排除的解释。
