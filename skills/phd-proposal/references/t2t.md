# T2T与基因组资源开题

从原T2T工作流推广；不预设物种、品种、测序平台或覆盖深度。

- 检索俗名/拉丁名、T2T/完整/无缺口/分相等概念，按目标补充着丝粒、rDNA、重复、结构变异或泛基因组。论文检索还需核对Assembly/BioProject等原始记录与版本。
- 最接近工作记录个体数、性别、数据、主组装/混合/分相表示、缺口、端粒与着丝粒证据、碱基准确性、分相准确性和实际应用；未报告填“未报告”，不是零。
- 分别定义单条染色体T2T、全基因组无缺口、双单倍型完整。contig末端有端粒重复、BUSCO高或N50大均不能独立证明T2T。
- 分开验证碱基准确性、基因完整性、染色体连续性、相位、污染、困难重复区；记录评估数据是否独立。Hi-C和共线性不单独证明每个碱基正确。
- 结构差异的竞争解释包括真实变异、塌缩、单倍型重复、组装/比对/注释差异；生物学推断前设计区分检验。
- 参考比较控制相同输入reads、过滤、注释与可比较区域；新增覆盖区域单列，记录参考亲缘偏倚和坐标转换。
- 一个参考个体支持资源贡献，不能直接建立品种频率、性状关联或因果结论；染色体和基因数不能增加生物学样本量。
- 用实际读段、分相资源和算力选择工具；给命令前查当前原始文档，不将候选软件名当成固定流水线。
- 预设无法闭合时的可交付边界：高质量染色体级、部分T2T及剩余困难区域。不要把“必然补齐所有缺口”当作可行性。
