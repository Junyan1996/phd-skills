# 通用章节映射

此表是内容清单，不是任何学校的官方格式；没有模板时据此起草，收到模板后重新映射，不混用其他学校附件。

| 内容 | 应回答的问题 | 核验重点 |
|---|---|---|
| 封面与基本信息 | 课题、学生、导师、学位、日期 | 只用真实信息；不伪造签名、意见和审批 |
| 目的与意义 | 具体限制是什么，解决后改变什么 | 区分科学、方法、资源、应用价值 |
| 理论与前期依据 | 为什么可能成立，已具备什么 | 文献、用户结果与计划分别标明 |
| 研究现状 | 最接近工作做到哪一步 | 按问题/证据组织，比较口径与研究版本清楚 |
| 问题、目标与内容 | 要回答什么，做到哪一步可验收 | 目标与学位、时间、数据相称 |
| 方法与路线 | 怎样获得区分性证据 | 样本/重复、比较、混杂、统计、验证和备选 |
| 创新与预期成果 | 支持哪些差异，产出什么 | 检索边界、非阳性结果、适用条件 |
| 可行性与风险 | 哪些前提未证实，如何尽早检验 | 资源依赖、触发条件、止损/转向方案 |
| 进度 | 何时交付什么 | 真实起止时间、外部依赖、验证与返工缓冲 |
| 文献与附件 | 能否找到原始支持 | 引文身份/支持/格式分别核验，正文编号一致 |

专业型、学术型及不同学位的考核不同，不将“博士必须三个机制目标”或“硕士只能描述”当作通则。资源项目也可以严谨立题；目标规模由实际要求与贡献决定。
