# 分析类型的关键检查

| 类型 | 设计与质控重点 | 验证边界 |
|---|---|---|
| RNA-seq | 样本表、链特异、计数单位、配对/区组、批次与组别、对比与多重检验 | 富集不等于通路被激活；表达关联不证明调控 |
| 单细胞/空间 | 个体与细胞层级、批次、双细胞/环境RNA、注释置信、整合对组间差异的影响 | 同一个体的细胞不是新增个体；伪时序不是实际时间或谱系证明 |
| GWAS/群体遗传 | 样本/位点QC、亲缘结构、等位基因方向、参考版本、群体与人口史、环境 | LD定位的候选不是致因；跨群体效果和可迁移性另验证 |
| 育种预测/机器学习 | 按个体/家系/时间/地点拆分，训练内预处理与特征筛选，嵌套调参，公平基线 | 独立测试不得参与模型选择；近亲随机拆分可能高估外推 |
| 组装/泛基因组/SV | 读段类型、分相资源、表示与坐标、污染、重复塌缩、困难区域、正交支持 | 连续性、准确性、相位和完整性分开；单个组装不代表群体 |
| 宏基因组/微生物 | 宿主/环境独立单位、阴性对照、污染、参考库、组成性和检出限 | 相对丰度不等于绝对数量；功能预测不等于实测活性 |
| 多组学 | 样本匹配、缺失机制、每层预处理、数据泄漏、相对单层基线的增益 | 跨层相关及网络边不直接给出因果方向 |

变异文件须核对参考/注释版本、染色体命名、链方向、0/1-based坐标和多等位位点处理。跨版本转换保留失败/多重映射记录。来源相同的衍生数据不能重复计为独立验证。
